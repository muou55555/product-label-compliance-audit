## 一、进口：在华注册编号

依据《进口食品境外生产企业注册管理规定》（海关总署令第248号）：
- 进口食品的内外包装应标注海关总署授予的在华注册编号；
- 企业须经海关注册且在有效期内；注销/撤销/过期的，其产品不得进口；
- 注册有效期一般为 5 年，届满前需按规定延续。

## 二、编号结构与含义（以葡萄酒为例）

`CGEO23012201060023`（共 18 位）：

| 段 | 取值 | 含义 |
|---|---|---|
| 1 | C | 在华注册标识 |
| 2 | GEO | 国家代码（格鲁吉亚） |
| 3 | 2301 | 产品类别代码（葡萄酒） |
| 4 | 220106 | 注册日期（2022-01-06） |
| 5 | 0023 | 顺序号 |

不同类别编号段含义按主管部门编码规则解读；先做结构合规校验，再联网核查状态。

## 三、核查方式（优先官方系统）

1. **首选官方查询渠道**：海关总署“进口食品境外生产企业注册信息”系统
   （中国国际贸易单一窗口 ciferquery），编号直查一般免登录；
2. 优先真实浏览器 GUI：打开页面→输入编号→查看企业/类别/注册日期/有效期/状态；
3. 若直连数据接口返回加密或被重定向，不要反复硬试，改用浏览器；
4. 企业名称模糊查询可能要求实名登录，无凭证时不要强行操作；
5. 截图留存作为证据。

### 两种执行通道（按平台能力二选一）

- **有浏览器 skill（如 browser-task）**：用真实浏览器 GUI 手工/半自动操作上述步骤。
- **没有浏览器 skill**：直接运行 `scripts/query_customs.py`（Playwright 浏览器自动化兜底），
  自动打开页面、填编号、查询、抓取结果并截图，输出结构化 JSON：

  ```bash
  pip install playwright
  playwright install chromium
  python scripts/query_customs.py CGEO23012201060023 \
      --out customs_result.json --shot evidence_customs.png
  ```

  输出含：`records`（国家/类别/企业/注册日期/有效期/状态）、`verdict`（自动判定）、
  `decoded`（编号逐段解码）、`open_items`（报关日期/库存/重新注册等人工开放项）。
  官方数据接口直连会返回加密/重定向，故脚本同样走浏览器（headless），不直连数据接口。

## 四、状态判定与处置

| 状态 | 判定 | 处置 |
|---|---|---|
| 有效且在有效期内 | 符合 | 正常 |
| 注销/撤销/过期 | 不符合 | 不得进口；新进口须用重新注册的有效编号并换标 |
| 查不到/编号不匹配 | 不符合/待核实 | 核对编号真伪、企业与类别是否一致 |
| 无法联网 | 待联网 | 补充核验，不定案 |

时间相关的人工核查（须保留为开放项）：
- 该批次实际报关/启运日期是否早于失效日期；
- 有效期内已合法进口的库存能否继续销售，须属地海关/市场监管认定；
- 企业是否已重新注册并取得新编号。

## 五、国内资质

- 国内生产：食品生产许可证编号（SC）、产品标准代号（进口可免标准代号）；
- 进口：原产国（地区）+ 境内依法登记的代理商/进口商/经销者名称、地址、联系方式；
- 许可证、注册编号格式与真伪按相关规定核验。
